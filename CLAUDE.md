## What This Is

Kate Feingold's personal academic website built on [al-folio](https://github.com/alshedivat/al-folio) — Jekyll 4.x with Liquid templating, Ruby gems, SCSS, and JavaScript. Deployed to GitHub Pages via GitHub Actions (`main` → `gh-pages` branch auto-built by CI).

## Commands

### Local Development

```bash
bundle exec jekyll serve --port 4000  # http://localhost:4000
```

### Code Formatting (required before every commit)

```bash
npm install --save-dev prettier @shopify/prettier-plugin-liquid  # first time only
npx prettier . --write
```

## Architecture

| Directory/File             | Purpose                                                      |
| -------------------------- | ------------------------------------------------------------ |
| `_config.yml`              | Primary config: URL, author, feature flags, analytics        |
| `_data/socials.yml`        | Social links: email, GitHub, LinkedIn, Scholar ID, X, Medium |
| `_data/coauthors.yml`      | Co-author names → profile URLs (auto-links in publications)  |
| `_data/cv.yml`             | CV in RenderCV YAML format                                   |
| `_pages/about.md`          | Home page — bio text, profile pic, news/posts toggles        |
| `_pages/`                  | Other static pages (cv, publications, projects, teaching)    |
| `_bibliography/papers.bib` | BibTeX publications (managed by jekyll-scholar)              |
| `_news/`                   | News/announcement entries shown on home page                 |
| `_projects/`               | Project showcase entries                                     |
| `_teachings/`              | Course/teaching pages                                        |
| `_posts/`                  | Blog posts — must be named `YYYY-MM-DD-title.md`             |
| `_includes/`               | Reusable Liquid components                                   |
| `_layouts/`                | Page layout templates                                        |
| `_sass/_themes.scss`       | Theme color (`--global-theme-color`)                         |
| `_sass/_variables.scss`    | All color/font variables                                     |
| `assets/img/`              | Images (profile pic goes here); `assets/pdf/` for papers     |

**Key architecture notes:**

- `_config.yml` drives feature flags (`enabled: true/false`) for all major sections
- The `gh-pages` branch is auto-generated by CI — never edit it directly; all changes go to `main`
- Deploy takes ~4-5 min after pushing to `main`
- To disable unwanted template sections without deleting files, add them to the `exclude` list in `_config.yml`

## Site Owner Configuration

When personalizing, the primary files to edit are:

**`_config.yml`** — update these fields:

```yaml
first_name: Kate
last_name: Feingold
url: https://kate-feingold.github.io
baseurl: # empty for root site

scholar:
  last_name: [Feingold]
  first_name: [Kate, K.]
  # Controls which author name is underlined/highlighted in publication lists
```

**`_data/socials.yml`** — social links appear on about page and in search:

```yaml
email: ...
github_username: kate-feingold
linkedin_username: katefeingold
scholar_userid: IXJGjcwAAAAJ # from scholar.google.com URL
x_username: kate_feingold
medium_username: katefeingold
```

**`_data/coauthors.yml`** — add co-author URLs so their names auto-link in `papers.bib`:

```yaml
"dekel":
  - firstname: ["Tali", "T."]
    url: https://www.weizmann.ac.il/math/dekel/
```

## Publications (BibTeX)

Add entries to `_bibliography/papers.bib`. Custom al-folio keywords:

- `selected={true}` — show on about page in "Selected Papers" section
- `preview={image.png}` — thumbnail (place image in `assets/img/publication_preview/`)
- `pdf={filename.pdf}` — link to PDF in `assets/pdf/`
- `code={https://...}` — "Code" button
- `website={https://...}` — "Website" button
- `blog={https://...}` — "Blog" button
- `abbr={CVPR}` — venue badge (add venue to `_data/venues.yml` for a link)

## Critical Configuration

When changing `_config.yml` URLs, these must match:

- Personal site: `url: https://username.github.io` + `baseurl:` (empty, but the key must exist)
- Project site: `url: https://username.github.io` + `baseurl: /repo-name/`

YAML special characters (`:`, `&`, `#`) in values must be quoted: `title: "My: Cool Site"`

## Commit Message Format

```
<type>: <subject>
```

Types: `feat`, `fix`, `docs`, `style`, `config`, `chore`

Always stage files explicitly (`git add <file>`), not `git add .` blindly.

## Common Pitfalls

- **Prettier CI failure:** Run `npx prettier . --write` and commit before pushing.
- **CSS/JS not loading after deploy:** Check `url`/`baseurl` in `_config.yml`; clear browser cache.
- **"Unknown tag 'toc'" on deploy:** Verify `gh-pages` is the deployment source in Settings → Pages.
- **Port in use:** `docker compose down`, then retry.
- **Related posts error ("Zero vectors cannot be normalized"):** Add content to posts or set `related_posts: false` in frontmatter.
- **ImageMagick required** for image processing — installed automatically in Docker.
- **Profile pic:** Name it `prof_pic.jpg` (or update `image:` in `_pages/about.md` frontmatter) and place in `assets/img/`.
